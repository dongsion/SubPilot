# SubPilot · 订阅管家

一款精致的订阅管理 + 个人记账 PWA 应用。黑金配色，移动端优先，所有数据本地存储，支持离线使用。

## 功能

- **订阅管理**：追踪所有订阅服务，支持周/月/季/年计费周期，自动识别品牌，环形进度条显示续费进度
- **自动扣款**：订阅到期自动从关联账户扣款，生成流水记录
- **账户管理**：银行卡/支付宝/微信/自定义钱包，层叠卡片设计
- **记账流水**：收入/支出双模式，8个支出分类 + 4个收入分类，按日期分组
- **数据可视化**：7天支出柱状图、月度支出环形分布图
- **PWA支持**：可添加到手机主屏幕，离线可用
- **数据备份**：JSON格式导出/导入

## 技术栈

- 纯原生 HTML/CSS/JavaScript，零依赖
- LocalStorage 数据持久化
- Service Worker 离线缓存
- PWA Manifest

## 本地开发

```bash
cd docs
python3 -m http.server 8080
```

浏览器访问 `http://localhost:8080`

## 部署

推送到 GitHub 后在仓库 Settings → Pages 中选择 `main` 分支 `/docs` 目录即可自动部署。
